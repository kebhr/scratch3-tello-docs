## Nov 7, 2022 / v1.3.1 is released

- Added support for German

Download it from [here](https://github.com/kebhr/scratch3-tello/releases/tag/v1.3.1).

## Nov 2, 2022 / v1.3.0 is released

- Added support for Tello EDU
- Added support for French
- Improved command execution logic
- Added `flip` command
- Added `reset command queue` command

Download it from [here](https://github.com/kebhr/scratch3-tello/releases/tag/v1.3.0).
