# Privacy Policy

## About Access Analysis
This site uses Google Analytics, an access analysis tool provided by Google. Google Analytics uses cookies to collect data. This data is collected anonymously and cannot be used to identify you personally.
You can disable this feature by disabling cookies in your browser. For more information about Google Analytics, please refer to [Google's policy page](https://policies.google.com/technologies/ads?hl=en).
