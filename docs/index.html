    Scratch3-Tello#

    Let’s fly Tello with Scratch 3.0!

    About#

    Scratch3-Tello is software that allows you to program Tello using Scratch 3.0.

    Since it is implemented as an extension of Scratch 3.0, which is widely used in programming education, there is no need to learn new software—you can focus entirely on programming the drone.

    Features#

    Scratch3-Tello is FREE to use. No license or attribution is required. You are free to use it in educational settings, workshops, programming schools, and training programs.

    Because it uses the standard Scratch 3.0 interface, learners won’t be confused by an unfamiliar UI.

    It is also compatible with the Tello EDU mission pad.
